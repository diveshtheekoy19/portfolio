# Diveshanand Theekoy: Portfolio

My personal portfolio website. I'm a Diploma in IT (Cybersecurity) student at Polytechnics Mauritius.

**Live site:** https://diveshanand-theekoy.vercel.app

## What's on it

- Education and work experience
- Projects: Life Powered by Tech (hackathon), an enterprise network lab in Cisco Packet Tracer, and a Blackjack game
- Certificates and skills
- Contact links

## How it's built

- Plain HTML, CSS and JavaScript, with no framework and no build step
- All content lives in `content.js`; `main.js` renders it into the page
- Hosted on Vercel; every push to `main` deploys automatically
